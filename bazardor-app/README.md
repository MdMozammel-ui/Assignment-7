# BazarDor — বাজারদর

BazarDor is a web application that helps users explore daily prices of essential products across different markets in Bangladesh.

## Features

- View daily prices of essential products.
- Browse products by category.
- Compare minimum, maximum, and average market prices.
- View product details and market-wise prices.
- Sort products by price from low to high or high to low.
- User authentication with email and password.
- Google and GitHub social login.
- Protected product details for authenticated users.
- Update profile name.
- Responsive design for desktop, tablet, and mobile devices.
- Loading skeletons, 404 pages, and toast notifications.

## Technologies Used

- Next.js
- React
- TypeScript
- Tailwind CSS
- Better Auth
- Neon PostgreSQL

## Getting Started

### 1. Install dependencies

```bash
npm install
```

### 2. Configure environment variables

Create a `.env.local` file in the project root and add the required environment variables.

Never publish secret keys or database credentials.

### 3. Run the development server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Project Purpose

BazarDor aims to make daily market-price information easier to explore and compare, helping users make informed purchasing decisions.
